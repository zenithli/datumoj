# datumoj NAS 备份状态页：离线共享候选

本候选供开发与审查使用，**全部输入为合成数据，尚未接入真实 NAS**。前端和构建脚本均不调用 AI，也不访问 NAS、R2、GitHub API 或凭据。

它复用已有 NAS 优先页面的布局方向，但没有复制私有快照。真实数据接口、可公开字段及更新时间要求仍需确认。

## 当前可验证的范围

- NAS 备份优先展示，分别呈现作业结果、存在与大小对账、内容哈希核验、恢复抽测。
- 严格的JSON字段白名单；未知字段和非法输入报错，不回显输入中的敏感值。
- 缺失或过期证据显示当前状态未知，历史观测单独展示。重新生成文件不刷新旧观测的有效期。
- 页面可读取同源status.json，并通过普通JavaScript刷新，不依赖AI。
- 普通Python脚本校验合成输入并构建静态目录。没有启用发布、定时任务或Pages。

## 为什么现在只接受合成模式

通过类型校验不等于已获得公开权限。候选只接受data_mode=synthetic，不能用一个命令开关绕过真实汇总字段的许可与接口审查。

不接受自由文本、主机名、IP、路径、账户、对象清单、原始日志、密钥、令牌或任意URL。真实导出器应先在私有侧完成汇总与脱敏，再由经批准的发布流程传出；不能把原始日志先写入公共仓库再清洗。

## 四类证据互不替代

- 作业完成只说明任务报告完成。
- 零缺失和零大小差异只对应那份对账快照；零个对象检查不能证明完整覆盖。
- 内容哈希抽样不是全量哈希验证。
- 恢复抽测不是全部数据的可恢复性保证。

任何一个绿色或通过标记都不是删除许可。本页面没有备份、删除或生产控制按钮。

## 自动更新的实际边界

候选的浏览器刷新与本地构建可以由普通程序运行，无需AI，但真实NAS数据更新尚未接通。

各分项的真实生成频率和过期阈值尚未确认，所以默认不能确认其当前有效性。页面分别显示文件生成时间、证据观测时间和页面读取时间，避免把“刚读取旧文件”误说成“刚完成备份”。

最终更新延迟取决于NAS导出周期、发布周期、构建时间与页面轮询；这里不承诺实时或固定分钟延迟。

## 本地运行和验证

需要 Node.js 20+ 和 Python 3.12+ 标准库，不需要安装依赖。以下命令在本目录运行：

```sh
node --test tests/*.test.js
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 -B tools/build.py --mode synthetic --input examples/synthetic-status.json --output synthetic-dist
```

输出目录必须尚不存在。也可运行 `sh examples/build-synthetic.sh NEW_DIRECTORY`。构建器不会连接网络或部署网页。将生成目录交给普通静态服务器即可预览；不要用 `file://` 代替 HTTP 模块环境。不要把本示例接入实际 NAS 导出目录。

当前输入契约在 `examples/synthetic-status.json`。顶层只有版本、合成模式、文件生成时间和四类 NAS 证据；时间采用 UTC 秒精度，计数允许空值。前端只读取同源 `./status.json`。构建器拒绝额外字段、重复 JSON 键、非法时间、非整数计数和非合成模式，并仅复制固定的网页资产清单。页面中的日期与数值都是虚构示例。

构建命令是可自动执行的普通程序样例，不是已经安装的计划任务。没有 GitHub Actions 工作流、Pages 配置或实际发布目标。

## 验证与限制

具体运行结果见 `verification.json`。测试覆盖字段白名单、时间有效性、缺失值、不同证据范围、请求超时、旧响应与停止后响应、读取失败、页面绑定以及构建失败时不生成最终目录。测试通过不是数据备份成功或生产验收。

目前验证环境为 Linux、Node.js 24、Python 3.12。未在 Windows 或最低声明 Node.js 20 上验证。构建器用于受信任的本地工作目录，不是防御恶意并发改写目录的服务。

## 集成前需要的审查

- 确认 NAS 负责人提供的时间语义、输出范围、采集周期、失败记录及过期条件。
- 列出所有者批准公开的真实汇总字段。结构校验并不能证明一个数字已获公开许可。
- 为真实适配器补测试：断线、部分完成、无回执、旧回执、未来时间、时间倒退、任务成功但校验失败、范围变化和权限失败。
- 37 给出并完成独立验收；Muse 只中继对应已验收版本。
- 启用公开托管或真实自动发布需另行授权。本候选没有执行这些操作。

## 原创欢迎封面

入口采用为 datumoj 绘制的原创像素档案小伙伴，保持深色背景与卡通队伍的视觉方向，未复制托管平台的登录 GIF 或标志。它是应用内欢迎页，不替代登录门禁。

完整页面加载后约 1 秒进入工作台，可用“直接进入”提前跳过。减少动态偏好采用静态画面后切换；正常显示仅在尾部轻淡出。页面内锚点跳转不会重播。欢迎页不等待数据加载、不改变 NAS 状态，也不会自动抢走键盘焦点。
